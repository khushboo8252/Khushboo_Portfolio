# Khushboo Kumari — Portfolio

A React + Tailwind CSS single-page portfolio.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually http://localhost:5173).

## Build for production

```bash
npm run build
```

This outputs a static site in the `dist/` folder, which you can deploy to
Vercel, Netlify, GitHub Pages, or any static host.

## Files

- `src/Portfolio.jsx` — the portfolio component (all content, sections, styles)
- `src/App.jsx` — mounts the Portfolio component
- `src/main.jsx` — React entry point
- `src/index.css` — Tailwind directives
